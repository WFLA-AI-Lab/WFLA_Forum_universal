# Changelog

本项目所有值得记录的变更都写在这里。格式参考 [Keep a Changelog](https://keepachangelog.com/zh-CN/1.1.0/)，
版本号遵循 [SemVer](https://semver.org/lang/zh-CN/)。

## [0.5.1] - 2026-10-26

### Fixed

- 修复 Windows PowerShell 5.1 直接运行中文脚本时的编码解析错误：一键配置脚本改为带 BOM 的 UTF-8。
- 一键配置脚本可在 UNC 共享盘路径下直接运行，不再依赖 `cmd.exe` 当前目录或 `npm.cmd`。
- 自托管迁移、建号、测试账号和备份脚本统一以脚本所在项目根目录解析 `.env`、数据库、迁移和备份路径，从任意当前目录运行都不会误写到本机仓库。
- 一键配置默认复用已有前端构建产物；需要重编译时使用 `-BuildFrontend`，无人值守复用现有配置使用 `-ReuseExisting`。
- 修复共享包缺少前端 `node_modules` 时一键配置误判为部署失败的问题。
## [0.5.0] - 2026-10-26

### Security

- 待激活账号不再能通过密码登录，也不会因为邀请码提议了高角色而获得任何管理权限。
- 所有权限检查统一要求账号状态为 `active`；禁言、封禁、待激活账号无法行使监管或管理权限。
- 隐藏话题对普通用户和游客彻底不可直达；隐藏回复也从话题详情中移除。

### Added

- 监管者及以上可以使用独立管理后台：概览、账号身份、内容、举报、审计和自动监管。
- 举报详情新增完整上下文：举报人、被举报对象、作者、真实姓名、届别与内容摘要。
- 举报处理 / 驳回会通知举报人；处理说明写入审计日志。
- 新增自动监管规则：举报阈值、高风险词、高链接密度、重复灌水、新用户高频发布。
- 自动隐藏会生成风险事件并通知监管者，管理员可在后台启停规则和调整阈值。
- 新增申诉接口：被禁言 / 封禁用户可提交申诉，监管者可复核并通过后恢复账号。
- 新增临时处罚字段与到期自动恢复；自动恢复同样写入审计日志。
- 举报提交增加服务端限流，防止恶意刷举报。

### Fixed

- 补齐密码重置、编辑 / 删除回复、自动处置、申诉复核等操作的审计缺口。
- 内容状态变更审计记录增加操作前后状态，便于追溯。

### Changed

- 数据库结构升级至 `SCHEMA_VERSION=13`，新增 `moderation_rules`、`risk_events`、`appeals` 与 `sanctions.resolved_at`。


## [0.4.1] - 2026-10-25

### Fixed

- 修复管理后台邀请码“复制”按钮在普通 HTTP 站点没有反应的问题。复制改为优先使用 Clipboard API，兼容回退到本地文本复制，并在浏览器完全禁用复制时弹出可手动复制的完整邀请码。
- 邀请码列表改为显示完整邀请码，便于发放前人工核对。
- 统一修复管理后台“复制初始密码 / 临时密码”按钮的同类非安全上下文兼容问题，并在复制成功或失败时给出明确反馈。

### Security

- 复制失败时不再静默失败；不会把邀请码、密码或其他敏感信息发送到第三方服务。
- 本次无数据库结构变更，`SCHEMA_VERSION` 保持 **13**。

## [0.4.0] - 2026-10-25

### Added

- **分级邀请码**：邀请码可指定注册后的目标角色：成员、监管者或管理员。旧邀请码自动视为成员邀请码。
- **权限边界**：owner 可生成管理员邀请码；admin/owner 可生成监管者或成员邀请码。任何人都不能生成同级或更高权限邀请码，也不能激活同级或更高权限账号。
- 邀请码列表显示目标角色，注册与邀请码发放 / 吊销均写入审计日志。

### Changed

- 注册后账号仍为 `pending`，必须由有权限的管理员在后台手动点击“审核并激活”后才正式生效。
- 账号详情支持即时变更权限（角色），下一次请求即按新权限判定，无需重新登录。

### Security

- 邀请码角色写入数据库并由服务端强制校验，不能通过修改前端请求绕过。
- 管理员邀请码只能由 owner 发放和激活，避免管理员自行扩张同级权限。

## [0.3.0] - 2026-10-25

### Added — 独立管理后台

- 新增全屏独立管理后台（仅 `admin` / `owner` 可用），与论坛皮肤解耦，切换皮肤不会改变后台布局。
- 概览页：账号 / 内容 / 举报 / 邀请统计、14 天活跃趋势、角色分布、待办提醒、热门话题与最近管理动作。
- 账号管理：搜索筛选、创建账号、角色变更、手动激活、禁言 / 封禁 / 恢复、密码重置、撤销全部会话、管理备注和第三方绑定查看。
- 内容审核与举报队列：隐藏 / 恢复 / 锁定话题和回复，处理或驳回举报，操作原因写入审计日志。
- 邀请码管理：生成、查看状态、复制与吊销；使用过的邀请码不可再次使用。
- 公告与板块：发布 / 删除全站公告、创建板块。
- 审计日志：按动作和关键词筛选最近 200 条记录。
- Owner 专属外观 / 高级设置 / 系统诊断：皮肤白名单与默认布局、游客只读、邀请注册、OAuth 凭据、会话策略和第三方连通性。
- 新迁移 `0010_admin_console.sql`：`user_notes`、`sanctions`、邀请码吊销字段与查询索引；`SCHEMA_VERSION` 升至 10。

### Changed

- 全站“届别”统一按**入学年份**理解：2026 年入学 = 2026 届；注册提示、管理后台、脚本和 API 文档同步更新。
- 管理后台采用 Apple 风格的独立视觉系统，支持响应式布局、深色模式、减少动态 / 透明度偏好和键盘焦点样式。
- 版本更新至 `0.3.0`；README、架构文档、API 文档与发版说明同步当前实际部署形态（Node.js + SQLite + 内网穿透）。

### Security

- 管理员只能创建、管理、授权或激活权限严格低于自己的账号；不能操作同级、更高权限或自己。
- Owner-only 设置继续要求当前密码确认；OAuth Secret 不回显。
- 管理操作写入审计日志，处置历史写入 `sanctions`。

- **跨设备皮肤偏好（API /api/v1/me/preferences）**：登录用户选择的界面皮肤保存到账号；

## [0.1.0] - 2026-10-25

首个可交接的版本：后端功能完整、可自托管，前端支持**可插拔布局皮肤**，仿 X 风格为默认主界面。

### Added — 后端

- 邀请制注册：邀请码一次性、可设有效期；注册后用户为 `pending`，须管理员在后台**手动激活**。
- 身份体系：内部账号密码登录 + 会话 Cookie（HttpOnly，生产 `Secure` + `SameSite=Strict`）。
- 第三方登录：GitHub 与 Microsoft OAuth（登录 / 绑定两种模式），可在管理后台可视化配置。
- 权限模型：`member` → `moderator` → `admin` → `owner`，默认拒绝，逐级「大于等于」判定。
- 内容系统：板块、话题、回复（Markdown 渲染 + 服务端白名单净化）、编辑、软删除、浏览量。
- 互动系统：点赞 / 点踩、收藏、全局搜索（话题 / 回复 / 用户）。
- 公告与通知：全站公告（按级别与时间生效）+ 站内通知（回复、公告、举报等）。
- 举报与监管：举报队列、分配、处理 / 驳回，话题与帖子的隐藏 / 锁定，操作原因强制填写。
- 审计日志：邀请、用户状态 / 角色变更、监管处置、公告、站点配置等敏感操作全部留痕。
- 用户管理：用户列表、创建账号、角色调整、状态调整（激活 / 禁言 / 封禁）。
- 运行时高级设置（仅 owner）：站点公开地址、会话参数、OAuth 凭据可视化配置，改密钥需二次确认密码。
- 网络诊断（仅 owner）：主动探测 GitHub / Microsoft 端点连通性并给出排查提示。
- 站点公开配置接口 `GET /api/v1/site/config`：品牌、版本、皮肤清单、游客 / 注册开关。
- 健康检查 `GET /api/v1/health`：返回应用版本、API 版本、数据库结构版本；实现收敛到可复用的 `healthRoutes` 模块。
- 自托管支持：SQLite（better-sqlite3）、迁移脚本、备份脚本、一键配置 / 一键启动脚本、可选 Caddy HTTPS。

### Added — 前端

- **皮肤架构（Skin Contract v1）**：容器（`App.tsx`）负责全部状态 / 请求 / 权限，皮肤是纯展示组件。
- **仿 X 风格皮肤**：三段式信息流布局，作为**默认主 UI**（`x`）。
- **Endfield 风格皮肤**：几何切割档案式布局（`endfield`），保留为备选皮肤。
- 皮肤注册表 + 懒加载：只下载当前皮肤代码块；皮肤切换持久化到 `localStorage`。
- 管理后台「外观」标签：owner 可切换默认皮肤与皮肤白名单，**立即生效、无需重启**。
- 游客可浏览公开内容；登录后才显示发帖、举报、通知等入口。
- 每位用户公开显示**真实中文姓名与入学届别**；管理员可查看全部真实身份（本论坛不允许匿名发帖）。

### Added — 工程与文档

- `docs/API.md`：完整接口文档（方法 / 路径 / 权限 / 请求体 / 响应 / 错误码）。
- `docs/FRONTEND_SKIN_GUIDE.md`：皮肤开发与交接指南。
- `docs/RELEASE_AND_ARCHIVE.md`：版本号规则、发版流程、迁移表、备份与存档约定。
- 单一版本来源 `src/version.ts`（`APP_VERSION` / `API_VERSION` / `SCHEMA_VERSION` / `SKIN_CONTRACT_VERSION`）。
- 数据库迁移 `0007_site_settings.sql`（站点皮肤与注册策略默认值）。

### Security

- 会话只存哈希、支持撤销；登录按 IP 限流；OAuth 使用一次性 state。
- 所有输入经 Zod 校验；正文 HTML 服务端白名单净化后再存储。
- 敏感字段（OAuth Secret、owner 密码）**永不回显**，接口只返回 `*_configured` 布尔值。
- 密钥、数据库、证书、私有部署教程均已排除在版本控制之外。
- 对 Git 历史做过安全重写，清除了曾误入的隐私 / 凭据内容。

### Notes

- `MAJOR` 仍为 `0`，接口与数据库结构在小版本内仍可能调整；破坏性变更会明确记录。
- 公告定义为**全站可见**的最显著横幅（如版本维护、紧急通知），不属于单个社团的内部公告。
