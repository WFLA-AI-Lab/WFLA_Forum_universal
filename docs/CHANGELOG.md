## [0.10.0] - 2026-10-28

### Added

- 动态与评论删除：作者可删除自己的动态/评论，监管者可删除任意内容；删除动态会软删除全部评论，删除评论会重算回复数，敏感操作写入审计日志。
- 私信的会话列表、会话标题和消息历史现在展示用户保存的昵称与头像；群成员接口同步返回资料信息。
- 发布归档新增 `archive/releases/v0.10.0`，记录版本、commit、契约、检查项与回滚目标。

### Fixed

- 修复 Windows PowerShell 下一键启动、一键配置和开机安装脚本同步 `frontend/dist -> public/` 失败的问题（`Copy-Item -LiteralPath "...\*"` 不展开通配符）。
- 安装脚本在 `frontend/dist` 缺失时明确报错，并在复制前清理 `public/`，避免旧 chunk 与新 `index.html` 混用。
- 同步所有面向协作者文档的当前版本号、Schema 版本和 API 示例，避免 README/API/架构/聊天文档继续显示历史版本。
- 修复前端离线兜底站点配置仍显示旧版 `0.1.0` 的问题；运行时兜底、package、lockfile 与 `APP_VERSION` 统一到 `0.10.0`。

### Changed

- 一键脚本的前端产物同步改为 `Get-ChildItem | Copy-Item` 管道实现，兼容 Windows PowerShell 5.1 与 PowerShell 7。
- 发布检查新增“所有文档中的当前版号与 `src/version.ts` 一致”的要求。

### Compatibility

- API：`v1`（不变）
- 数据库 schema：`14`（不变，本次无迁移）
- 皮肤契约：`3`（不变）

## [0.9.0] - 2026-10-27

### 新增

- 新增自托管私聊：唯一会话、文本消息、幂等发送、历史分页、5 秒轮询所需的增量接口、未读数、标记已读、屏蔽、本人删除 tombstone。

- 聊天自动监管：命中敏感词、链接密度、重复内容和洪水规则时记录风险事件并通知监管者，不自动隐藏聊天消息。

- 新增 `docs/CHAT_API.md` 与 `/#/chat-test` 临时验收页；正式前端 UI 由 Zx_实现。

- 仅验收 Node.js + SQLite 自托管部署；Cloudflare 兼容层保持编译，不新增 D1/R2/Durable Object 验收。
- 聊天 v1 不支持附件、回复、转发、搜索、编辑、typing、在线状态、已读回执和用户自建群。

## [0.4.0] - 2026-10-25

### Added

- **分级邀请码**：邀请码可指定注册后的目标角色：成员、监管者或管理员。旧邀请码自动视为成员邀请码。

### Changed

- 账号详情支持即时变更权限（角色），下一次请求即按新权限判定，无需重新登录。

### Security

- 邀请码角色写入数据库并由服务端强制校验，不能通过修改前端请求绕过。
- 管理员邀请码只能由 owner 发放和激活，避免管理员自行扩张同级权限。

## [0.1.0] - 2026-10-25

首个可交接的版本：后端功能完整、可自托管，前端支持**可插拔布局皮肤**，仿 X 风格为默认主界面。

### Added — 后端

- 邀请制注册：邀请码一次性、可设有效期；注册后用户为 `pending`，须管理员在后台**手动激活**。
- 身份体系：内部账号密码登录 + 会话 Cookie（HttpOnly，生产 `Secure` + `SameSite=Strict`）。
- 第三方登录：GitHub 与 Microsoft OAuth（登录 / 绑定两种模式），可在管理后台可视化配置。
- 权限模型：`member` → `moderator` → `admin` → `owner`，默认拒绝，逐级「大于等于」判定。
- 内容系统：板块、话题、回复（Markdown 渲染 + 服务端白名单净化）、编辑、软删除、浏览量。
- 互动系统：点赞 / 点踩、收藏、全局搜索（话题 / 回复 / 用户）。
- 公告与通知：全站公告（按级别与时间生效）+ 站内通知（回复、公告、举报等）。
- 举报与监管：举报队列、分配、处理 / 驳回，话题与帖子的隐藏 / 锁定，操作原因强制填写。
- 审计日志：邀请、用户状态 / 角色变更、监管处置、公告、站点配置等敏感操作全部留痕。
- 用户管理：用户列表、创建账号、角色调整、状态调整（激活 / 禁言 / 封禁）。
- 运行时高级设置（仅 owner）：站点公开地址、会话参数、OAuth 凭据可视化配置，改密钥需二次确认密码。
- 网络诊断（仅 owner）：主动探测 GitHub / Microsoft 端点连通性并给出排查提示。
- 站点公开配置接口 `GET /api/v1/site/config`：品牌、版本、皮肤清单、游客 / 注册开关。
- 健康检查 `GET /api/v1/health`：返回应用版本、API 版本、数据库结构版本；实现收敛到可复用的 `healthRoutes` 模块。
- 自托管支持：SQLite（better-sqlite3）、迁移脚本、备份脚本、一键配置 / 一键启动脚本、可选 Caddy HTTPS。

### Added — 前端

- **皮肤架构（Skin Contract v1）**：容器（`App.tsx`）负责全部状态 / 请求 / 权限，皮肤是纯展示组件。
- **仿 X 风格皮肤**：三段式信息流布局，作为**默认主 UI**（`x`）。
- **Endfield 风格皮肤**：几何切割档案式布局（`endfield`），保留为备选皮肤。
- 皮肤注册表 + 懒加载：只下载当前皮肤代码块；皮肤切换持久化到 `localStorage`。
- 管理后台「外观」标签：owner 可切换默认皮肤与皮肤白名单，**立即生效、无需重启**。

### Security

- 会话只存哈希、支持撤销；登录按 IP 限流；OAuth 使用一次性 state。
- 所有输入经 Zod 校验；正文 HTML 服务端白名单净化后再存储。
- 敏感字段（OAuth Secret、owner 密码）**永不回显**，接口只返回 `*_configured` 布尔值。
- 密钥、数据库、证书、私有部署教程均已排除在版本控制之外。
- 对 Git 历史做过安全重写，清除了曾误入的隐私 / 凭据内容。
